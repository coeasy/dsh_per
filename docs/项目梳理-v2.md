## 1. 项目定位（不变）

DSH（Cordis 宿主）上的多模型编排插件：把大任务拆成「规划 → 执行 → 复核」三阶段流水线，每阶段绑定不同模型，内置自动修复回路、计划审计协商、预算护栏与降级链。

**架构硬约束（不变）**：数据驱动的 FSM 迁移表是唯一控制中枢；引擎任何地方不直接改 `snapshot.state`，只能经 `task.transition()` / `forceAbort()`；turn 驱动轴（`agent/turn-stopping`）与事件驱动轴（`session/event`）唯一交汇于 `transition()`；配置五层解析（会话 override > settings 用户段 > saved-overrides > 补丁 config > schema 默认）。
