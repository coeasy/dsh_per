### C. 6 个死配置键逐个实现真实语义（D2）

> 全部当前为 `z.literal(...)` 单值枚举 → 扩展为多值枚举并接线。zod 默认 strip 未知键，旧补丁不受影响；单值旧配置值仍为默认值，行为不变。

| # | 键 | 现值 | 新枚举 | 接线点与语义 |
| --- | --- | --- | --- | --- |
| C1 | `fix_loop.strategy` | `'incremental'` | `'incremental' \| 'batch'` | `buildFixDirective`：`incremental`（现状）只带问题清单；`batch` 追加「按依赖关系批量修复、单轮收敛」指令并在 directive 头部标注批量模式 |
| C2 | `fix_loop.exhausted_delivery` | `'flagged'` | `'flagged' \| 'abort'` | 修复轮次耗尽的交付形态：`flagged`（现状）→ `review/fail-exec:DONE` 走 `deliverFlagged`；`abort` → 改走 `forceAbort('fix_cycle_exhausted')`。需给迁移表补 `fix/exhausted` 复合事件或引擎侧显式 abort |

### D. engine.ts 模块拆分（D1）

**拆分原则**：模块只接收 `EngineCtx`（共享状态包）与显式参数，**不自行持有可变闭包状态**；事件发射点、迁移调用、hooks 一律留在 `engine.ts` 核心，模块只做「构建 prompt / 派发子代理 / 记账 / 命令注册」四件事。

| 模块 | 迁出内容 | 依赖 |
| --- | --- | --- |
| `src/engine/ctx.ts` | `EngineCtx` 接口（ctx/cfg/effectiveConfig/task/registry/snapshots/ledger/agents/notice/logger/clock/…） | 无 |
| `src/engine/prompts.ts` | `skeletonPlan`、`buildFixDirective`、`buildReplanDirective`、里程碑文案构造函数、`MECH_SUMMARY` 等纯函数 | 无（纯函数，零风险） |
| `src/engine/child-run.ts` | `withTimeoutDispose`（含 A4 修复）、`resolveChildProvider` | logger |
| `src/engine/review.ts` | `buildReviewPrompt`（含预算三级裁剪）、`dispatchReviewPrompt`、`dispatchReviewer`（含分片）、`mergeShardedVerdicts` 接线 | review.ts（protocols）+ child-run |
| `src/engine/audit.ts` | `bindAuditor`、`dispatchPlanAuditors`、`runAuditGateIfPending` | plan-audit.ts（protocols）+ child-run |
| `src/engine/accounting.ts` | `resolvePricingRate`、`isUnpricedModel`、`accountUsage` | ledger + budget schema |
| `src/engine/commands.ts` | `registerCommands`（`/orch` 家族 + `/per` 家族） | registry + config |

`src/engine.ts` 保留：`createEngine` 入口、hooks 表、`handleUserInput`、`onSessionEvent`、`onTurnStopping`、`onRequest`/`onRequestError`、生命周期与监听器装配、`transitionOrLog`。目标规模：核心 ≤ 700 行。

**验收**：拆分前后 `vitest run` 全绿且用例数不减；`grep` 确认所有 `transitionOrLog(` 调用点仍在 `engine.ts`；`grep 'review/pass\|exec/ok:DONE\|budget/exhausted'` 在核心文件内。

## 5. 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 拆分导致闭包状态错置 | `EngineCtx` 集中持有全部可变状态，模块不持有闭包；每步拆分后跑全量测试回归 |
| 6 个新枚举值破坏旧补丁 | 默认值保持原单值；zod strip 未知键；CHANGELOG 显式记录 |
| `exhausted_delivery: 'abort'` 改变交付语义 | 默认 `flagged`（现状）；新值需用户显式配置才生效 |
| 墙钟检查脱离 usage 后更早触发 | 阈值不变（30min），只是「不记账的调用」不再豁免；属修正而非放宽 |
| `review/deadlock` 加 fallback 改变终止路径 | 仅 `fix_cycle` 到顶的极端分支受影响，走向 `DONE_FLAGGED` 而非 `guard_rejected` 强制中止，是更保守的交付 |
| 回滚 | 工作树整体未提交（仅 `LICENSE` 一处 diff），任何一步失败可直接 `git checkout` 回退到本批起点 |
