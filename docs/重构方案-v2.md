# dsh-per 重构方案（v2）

> 制定日期：2026-09-06 ｜ 基线：当前工作树（110 测试全绿，P0 全清）
> 前置文档：`项目梳理-v1.md`（架构与实现细节）、`优化改进方案-v1.md`（49 项全量方案）、`项目梳理-v2.md`（v1 落地状态复核）。
> 本方案是 **v2 执行批**：承接 v1 方案中尚未落地的 P1/P2 项，逐项给出当前根因（实测行号）、方案与验收。共 24 项实施 + 5 项明确延期。

## 0. 范围与原则

1. **不改变 FSM 迁移语义**：`transition-table.ts` 的行、`fsm.ts` 的 action 操作符一律不动；控制流改动仍以「引擎侧事件发射 + 守卫」为界。
2. **保持零 bundler**：web 客户端、`scripts/build-web.mjs` 不引入构建链；本批也不引入 linter 运行时依赖（见 §4 决策）。
3. **保持 `lib/` 与 `web/dist/` 入库**：`.gitignore` 注记明确——社区插件预构建约定（cf. dsh-at-file），git 安装必须免本地构建。
4. 每项改动附带可断言验收；批次出口：`tsc` + `vitest` + `ci:checks` 全绿，README 计数与实际一致。

## 1. P1 收尾（8 项）

### P1-06 删除 `plan_protocol` 死配置
- **根因**：`schema.ts:34` 声明 `builtin|fenced`（ADR #26），运行时只有 fenced 路径；`README.md:28`、`test/units.test.ts:56` 同步漂移。
- **方案**：删 schema 键 + README 行 + 测试断言（zod strip 语义下旧补丁不受影响）。
- **验收**：`grep plan_protocol src test README.md` 零命中；全绿。

### P1-07 ci-checks 第 5 项不变量：变体行可达性
- **根因**：`fsm.transition` 是「精确行优先」，无守卫的精确 `event` 行会静默屏蔽 `${event}:variant` 行；引擎靠显式发复合事件名（`exec/ok:DONE`）绕开，全靠人肉记忆，门禁不查。
- **方案**：`ci-checks.mjs` 新增不变量——对每个变体行，若同 state 存在无守卫的精确行，则要求 `src/engine.ts` 中出现该复合事件名字符串（`'exec/ok:DONE'` 等）的显式发射；否则 FAIL 并指出死行。同时统一 transition-table 顶部注释为「精确行优先」。
- **验收**：门禁通过；故意删除引擎发射点后门禁 FAIL（人工演练一次即可）。

### P1-10 复核 prompt 预算裁剪 + 分片复核接线
- **根因**：`buildReviewPrompt`（engine.ts）无条件注入完整计划 JSON + 全部历史 issues；`review.input_token_budget`（默认 50000）声明无读取方。大任务的复核 prompt 超限 → 停止原因异常 → 死锁链。`mergeShardedVerdicts`（review.ts:81）就绪但引擎始终单片。
- **方案**：
  1. **预算裁剪**：`estimateTokens(prompt) > input_token_budget` 时降级为骨架计划（steps 仅 id/title/files，丢 risk_note 与 JSON 冗余），历史 issues 只留最近 2 轮；仍超限则只留产物统计。裁剪事实写入 prompt 尾注。
  2. **分片复核**：`changedFiles.length > 12` 或 `diffLines > 800` 时按文件分片（上限 4 片）并行派发 reviewer，`mergeShardedVerdicts` 合并；单分片失败降级为单片全量复核。`estimateTokens` 用 P2-09 的 CJK 感知版本。
- **涉及**：`src/engine.ts`、`src/protocols/review.ts`（如需 sharded prompt 构造辅助）、`src/config/schema.ts`（复用既有 `review.input_token_budget`）。
- **验收**：新增单测——超预算计划被裁剪到 ≤ 预算；多分片合并取最严 defect/最低 confidence/id 去重；单片路径字节级不变（既有 engine-turn 用例回归）。

### P1-11 移除 `max_parallel_tasks` 无效配置
- **根因**：`registry.ts:83` 构造参数未被 `admit()` 使用；`schema.ts:122` 声明无效。
- **方案**：**v1 语义收敛（v1 方案推荐①）**：删配置键 + `TaskScheduler` 构造参数；README 记录「v1 严格串行（ADR #19）」。会话级并行（方案②）留待有真实需求时单独立项。
- **验收**：`grep max_parallel_tasks src` 零命中；排队/交接用例不回归。

### P1-13 快照落盘节流
- **根因**：`transitionOrLog` 每次迁移后 `snapshots.save()` 同步 write+rename（引擎热路径每次 LLM 调用 ≥ 1 次同步写）；ledger 已改脏标记，快照未改。
- **方案**：`SnapshotStore` 改脏标记 + `setImmediate` 合并写（同一 tick 多次迁移合并一次 IO）；**终态（DONE/DONE_FLAGGED/ABORTED）与 `abandoned` 快照仍同步立即落盘**（崩溃安全优先）；新增 `flushAll()`，引擎 `ctx.effect` 清理回调 + `process.once('exit')` 兜底。
- **涉及**：`src/persistence/snapshot.ts`、`src/engine.ts`。
- **验收**：新增单测——同 tick 连续 20 次 save，`writeFileSync` 计数 ≤ 2；终态 save 后文件立即可读；`flushAll()` 后无 dirty 残留。既有 recover 用例回归。

### P1-14 机械验证：可取消 + lint 实装 + summary 修正
- **根因**：`mechanical.ts` 无 AbortSignal（`user/cancel` 后子进程跑满 120s）；`runOne` 对 compile 也调 `summarizeTests`（误导性 summary）；`commands.lint` 声明不执行。
- **方案**：
  1. `run(files, opts?: { signal?: AbortSignal })`；abort → `child.kill('SIGKILL')` 并 resolve `unavailable`；`runReview` / quick channel 传入 turn 的 `payload.signal`。
  2. `summarizeTests` 仅对 `tests` 调用；compile/lint 只留 tail。
  3. lint 走同一 `runOne`，`MechanicalResult.lint` 新字段；quick channel 要求配置了的全部命令 pass。
- **涉及**：`src/protocols/mechanical.ts`、`src/engine.ts`、`src/types.ts`。
- **验收**：单测——abort 后子进程 <1s 结束；compile 结果无 summary；lint fail 禁止 quick channel。

### P1-16 CI workflow + 发布守门
- **根因**：无 `.github/workflows`；无 `prepublishOnly`；`lib/` 入库是约定（保留），但缺自动门禁。
- **方案**：
  1. `.github/workflows/ci.yml`：pnpm install → `tsc --noEmit` → `vitest run` → `ci:checks`（node 22）。
  2. `prepublishOnly: build + test + ci:checks`。
  3. **不引入 linter 依赖**（biome/eslint 均需装包，与零依赖理念相悖且当前收益低）；`settings/namespace.ts` 的 eslint-disable 注释一并清理。
- **验收**：workflow 文件语法有效（actionlint 级别人工核）；`pnpm run prepublishOnly` 本地可跑通。

### P1-18 README / 版本 / CHANGELOG 对齐
- **方案**：README 用例数改为与实际一致；补「已知限制」（严格串行、估价模式、i18n）；版本 0.1.0 → **0.2.0**（重构批次）；新增 `CHANGELOG.md`（0.1.0 / 0.2.0 两节，0.2.0 列本批 P1/P2 变更）。
- **验收**：README 计数 = `pnpm test` 输出；CHANGELOG 覆盖本批。

- `tsc --noEmit` 干净；`vitest run` 全绿（110 + 新增 ≥ 8 用例）；`ci:checks` 5 项不变量通过。

## 5. 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 快照节流导致崩溃丢中间态 | 终态/abandoned 保持同步落盘；中间态丢失窗口 ≤ 1 tick，恢复策略本就放弃非终态快照 |
| 分片复核改变判定语义 | 单片路径字节级不变；阈值隔离（≤12 文件且 ≤800 diff 行永不分片）；合并规则保守（最严 defect + 最低 confidence） |
| estimateTokens 变化影响 planDigested 阈值 | CJK 估算更接近真实消耗（原 ÷4 低估），方向安全；相关用例断言放宽为单调性 |
| 删配置键破坏旧补丁 | zod 默认 strip 未知键；CHANGELOG 显式记录 |
