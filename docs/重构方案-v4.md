## 3. 出口判据

- `tsc` + `vitest`（≥150 用例）+ `ci-checks`（**7 项**不变量）全绿。
- `grep -n 'againstDaily' src/budget/ledger.ts` 无 `void` 死用法；`count_passthrough` 要么有行为单测、要么从 schema 消失。
- `Date.now` 在 `src/task/`、`src/budget/` 中零直呼（统一走注入时钟）。
- README / CHANGELOG 与实现零漂移。
